取扱説明書（導入・設定）

📱 ホーム画面への追加（推奨）

本アプリは、スマートフォンのホーム画面に追加することで、アドレスバーが非表示になり、通常のスマホアプリと全く同じ「全画面表示」で快適に起動できるようになります。

🍎 iPhone (Safari) の設定手順

  1. Safari でアプリのURLを開きます。
  2. 画面下部中央にある「共有」ボタン（□から上矢印が出ているアイコン）をタップします。
  3. メニューを下へスクロールし、「ホーム画面に追加」を選択します。
  4. 画面右上の「追加」をタップすると、ホーム画面に「名刺読取」アイコンが追加されます。

🤖 Android (Chrome) の設定手順

  1. Chrome でアプリのURLを開きます。
  2. 画面右上にある「3つのドット（メニュー）」アイコンをタップします。
  3. メニューから「アプリをインストール」（または「ホーム画面に追加」）を選択します。
  4. 確認画面で「インストール」または「追加」をタップします。

📖 基本的な使い方

  1. ホーム画面のアイコンからアプリを起動します。
  2. 「カメラを起動して名刺を撮影」エリアをタップし、スマホのカメラで名刺を撮影します（または「ファイルから写真を選択」で画像ファイルを選びます）。
  3. プレビューを確認し、「名刺をスキャンする」ボタンをタップします。
  4. 数秒でAIが解析したテキストが画面下部に整理されて表示されます。
  5. 「コピー」ボタンをタップすると、クリップボードに一括コピーされますので、社内システムやExcelなどに貼り付けてご利用ください。

💡 事前設定の注意点
ご利用前に、画面右上の歯車マーク（設定）から「Gemini APIキー」が登録されている必要があります。（同一ブラウザで議事録アプリをご利用中の場合は、自動で引き継がれるため再設定は不要です）

🔒 セキュリティと個人情報の取り扱い

  • データの完全保護: 読み取った名刺の画像やテキストデータは、社内外のサーバーやデータベースに一切保存されません。
  • ブラウザ直接通信: 処理はすべて利用者のブラウザ（スマートフォン内）と、Googleの暗号化されたAPI通信（SSL/HTTPS）のみで完結するため、情報洩れや不正アクセスの心配がなく安全です。
