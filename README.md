# AI名刺読み取りアシスタント（導入・設定手順書）

本アプリは、スマートフォンのカメラで名刺を撮影するだけで、AI（Gemini）が会社名、氏名、連絡先などを自動的に整理・抽出してくれる社内専用の便利ツールです。

---

## 🔒 セキュリティと個人情報の取り扱いについて
* **データ保存なし**: 読み取った名刺の画像や、テキストデータは**社内外のデータベースやサーバーに一切保存されません**。
* **直接通信のみ**: 処理はすべて利用者のブラウザ（スマートフォン内）と、Googleの暗号化されたAPI通信（SSL/HTTPS）のみで完結するため、情報漏洩や不正アクセスの心配がなく、安全に利用できます。

---

## 📱 スマートフォンへのインストール方法（ホーム画面に追加）

本アプリは、スマートフォン（iPhone / Android）のホーム画面に追加することで、**アドレスバーが非表示になり、通常のスマホアプリと全く同じ「全画面表示」**でタップするだけで起動できるようになります。

以下の手順で、各スマートフォンの設定を行ってください。

### 🍎 iPhone (Safari) での設定手順
1. **Safari** を起動し、本アプリの公開URL（GitHub PagesのURL）を開きます。
2. 画面下部（または上部）の中央にある **「共有」ボタン（□から上矢印が出ているアイコン）** をタップします。
3. 表示されたメニューを下にスクロールし、**「ホーム画面に追加」** をタップします。
4. 画面右上の **「追加」** をタップします。
5. ホーム画面に **専用アイコン（「名刺読取」）** が追加されます。次回以降は、このアイコンをタップするだけで起動します。

### 🤖 Android (Chrome) での設定手順
1. **Chrome** を起動し、本アプリの公開URLを開きます。
2. 画面右上にある **「3つのドット（メニュー）」** アイコンをタップします。
3. メニューの中から **「アプリをインストール」**（または「ホーム画面に追加」）をタップします。
4. 確認画面が表示されるので「インストール」または「追加」をタップします。
5. ホーム画面に **専用アイコン（「名刺読取」）** が追加され、アプリとして起動できるようになります。

---

## 📖 基本的な使い方
1. ホーム画面のアイコンからアプリを起動します。
2. **「名刺の写真を撮影または選択」** エリアをタップし、スマホのカメラを起動して名刺を撮影します。
3. プレビュー画像を確認し、**「名刺をスキャンする」** ボタンをタップします。
4. 数秒〜十数秒で、解析されたテキストが画面に表示されます。
5. **「コピー」** ボタンをタップすると、結果がクリップボードに一括コピーされますので、社内の既存システム（SFA/CRM）やExcelなどにそのまま貼り付けてご活用ください。

> 💡 **注意点**
> * 画面右上の歯車マーク（設定）から、事前に「Gemini APIキー」が正しく設定されている必要があります。（同じブラウザで議事録アプリをご利用中の場合は、自動で引き継がれるため設定不要です。）
